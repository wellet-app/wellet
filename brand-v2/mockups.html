v2 UX mockups, screen by screen.

Side-by-side: the live mywellet.com today (left) versus the proposed v2 build (right). Same information architecture. New type stack (Gambetta + Public Sans replacing Fraunces + DM Sans), Mint micro-accents, one Midnight depth surface, italic-noun headlines, and glass on the visit-prep card.

Type: Fraunces + DM Sans → Gambetta + Public Sans
Accent: Forest only → Forest + Mint highlights
Depth: Cream-only → Midnight depth + glass on key moments
Voice: Italic-noun headlines, sourced eyebrows preserved

How to read this page.

Six screens, one language. The same card shape repeats wherever a unit of data has source + identity + status: a Forest 3px left border, a Clay eyebrow naming where it came from, and a Mint pill carrying the most useful fact. When something changes — a dose, a flag for next visit — the border and pill go Clay or Walnut, not Mint. That's the whole grammar.
